# 🧮 Calculator App

A simple, clean, and functional calculator built using HTML, CSS, and JavaScript.
The design is inspired by the Apple Calculator UI, and I recreated it myself for learning and practice purposes.

# 🚀 Live Demo : https://aziztarrouche0.github.io/calc_app/


# 📌 Features
Clean Apple-style UI

Addition, subtraction, multiplication, division

Clear (C) button

Fully responsive

Smooth button interactions

Simple and fast performance

 # 🛠️ Technologies Used

HTML

CSS

JavaScript
